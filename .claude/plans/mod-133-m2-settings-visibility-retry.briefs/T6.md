# MOD-133 M2 T6 brief

## Summary

The project default `integrate` becomes a project-only registry key edited in Settings > Prompt, and the
repo mode a choice row of the Hierarchy repo editor; both refuse `pull_request` (until MOD-134) and a
non-`local` mode where no remote URL exists. An item whose latest graph run is `done` with unlanded
records reads `landing`, or `landing refused` when one is refused. A refused record shows as a waiting row
(reason `landing`), and `Unblock` retries it: refused records go back to `pending`, and the executing
process lands them at once (the sweep stays the recovery path). `local` projects are byte-for-byte
unchanged. The `pull_request` run branch is M3; the close-out law (`done` requires landed) is MOD-135.
