## M1 - Stopped state and workspace gate (2026-10-20)

Plan `.claude/plans/mod-125-m1-stopped-state.plan.md` (`9d7679fa`), phase note `82a0f48b`. Migration
`0019_stop_runs`: resumable `stopped` run and step status (live, holds no slot, off the top-bar count),

## M2 - Stop applied by the executor (2026-11-12)

Plan `.claude/plans/mod-125-m2-stop-applied.plan.md`, phase note `15bd2f89`, review fixes merged `4b3c93e7`. The
command poll (TUI and worker alike) lists `pending_stops(owner)` and interrupts each walk through the cancel
seam: graceful `Cancel{CANCEL_GRACE}`, forced `Cancel{0}`, the token dropped at grace + `STOP_SLACK` 5 s; then it
retakes the lease and settles `stopped` (`Engine::settle_stop`), trees and session banner kept. A pending cancel
wins, and a stopped run takes no cancel row (store-serialised). Walking commands, `p` and an unblock resume are
refused in a stopped workspace; `admit` holds a stopped workspace's entries without using slots or draining the
batch; a dropped check kills its process group. M1 review deferrals landed: `delete_workspace` refuses while the
workspace has stopped runs (M-3), a readable refusal for a deleted workspace's foreign keys (L-3), `admit`'s half
of L-7, and every crate went `0.2.0` (L-5).

## M3 - Resume through saved sessions (2026-11-13)

Plan `.claude/plans/mod-125-m3-resume.plan.md` (`edaab6b9`), phase note `68c652bc`. A resume request is the
absence of the `workspace_stop` row (`resume_workspace`); the executing box's command poll lists
`pending_resumes(box)` and `Engine::resume_stopped` walks each run under a fresh lease. A stopped step resumes on
its own row: no session rows reruns from stage 1; rows without a banner, or an agent without resume caps,
continue fresh with the handoff text; a banner plus caps reopens the session (ACP load/resume, CLI `--resume`),
the session id read from the banner row (no column) and `STOP_RESUME_OPENING` asking the agent to redo a turn the
stop cut off. A reopen that fails on the wire records `resume_failed` and reruns fresh. Trees are retaken without
a reset (`Isolator::reacquire`; a checkout moved while stopped refuses); parts and candidates resume in their
rounds, the judge reruns fresh, `select_fanout` supersedes a stopped loser or judge (L-7). Every stopped run can
be cancelled (`cancel_stopped_run`: box-less at once, on its box with cleanup, another box through a cancel
row), so the demo's `RUN_8` cancels and `graphics` deletes. `docs/ANA-2.md` §4.3 and
`docs/decisions/mod/mod-24.md` amended (crash recovery unchanged; only an explicit stop resumes sessions).
